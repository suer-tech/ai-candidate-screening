## MODIFIED Requirements

### Requirement: SEC-003 [CONFIRMED] Хранение секретов
Сервисные credentials, OAuth client secrets, OAuth tokens и ключи MUST NOT храниться в коде, спецификациях или логах. Google Drive production access MUST использовать только server-side OAuth личного Gmail: client secret из разрешённого секрета, refresh token из callback в зашифрованном durable storage, operations внутри root `Найм`, наблюдаемый owner и recovery через `WAITING_FOR_HUMAN`. Готовый личный access/refresh token, вручную скопированный сотрудником или разработчиком в конфигурацию, MUST NOT использоваться. API-ключ RouterAI, токен Telegram-бота и OAuth token-encryption keys MUST поступать только из разрешённых секретов окружения. Конкретные значения MUST NOT записываться в OpenSpec или пользовательскую конфигурацию. Разрешённые Telegram `chat_id` MUST задаваться только серверной конфигурацией, не раскрываться клиенту, логам или сообщению.

#### Scenario: Компоненту нужен ключ
- **WHEN** интеграция запускается
- **THEN** ключ поступает из разрешённого механизма секретов

#### Scenario: Личный токен HR доступен разработчику
- **WHEN** настраивается production-интеграция Google Drive
- **THEN** готовый личный token не копируется разработчиком в конфигурацию
- **AND** refresh token получается только callback-границей и сохраняется зашифрованным

#### Scenario: Личный токен скопирован вручную
- **WHEN** оператор передаёт готовый access либо refresh token вне OAuth flow
- **THEN** конфигурация отклоняется

#### Scenario: Настраивается RouterAI
- **WHEN** оператор задаёт API-ключ провайдера
- **THEN** значение сохраняется разрешённым механизмом секретов
- **AND** отсутствует в коде, OpenSpec, логах и пользовательском интерфейсе

#### Scenario: Настраивается Telegram-бот
- **WHEN** оператор задаёт токен бота
- **THEN** значение сохраняется разрешённым механизмом секретов
- **AND** отсутствует в коде, OpenSpec, логах и пользовательском интерфейсе

#### Scenario: Настраиваются получатели Telegram
- **WHEN** оператор задаёт список разрешённых `chat_id`
- **THEN** значения сохраняются в серверной конфигурации
- **AND** не раскрываются клиенту, логам или содержимому сообщения
