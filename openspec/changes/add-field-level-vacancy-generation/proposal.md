## Why

HR должен иметь возможность генерировать содержимое профиля вакансии постепенно, контролируя промпт и сохраняя результат только после проверки, вместо обязательной полной перегенерации всего профиля. Текущий обязательный непустой ABC-шаблон также не соответствует согласованному потоку, в котором новая вакансия начинается с названий направлений, а описания A/B/C заполняются отдельно и остаются необязательными для анализа.

## What Changes

- Добавляется отдельная LLM-генерация для пустых полей «Образ результата», «Компетенции», «Стоп-факторы» и «Допуск к КЕ» с подтверждением, состоянием ожидания и немедленным заполнением черновика без перезагрузки.
- Для каждой вакансии и каждого генерируемого раздела сохраняется отдельный редактируемый промпт; фактический запрос использует сохранённый текст и по умолчанию содержит название вакансии.
- Добавляется отдельная ABC-генерация, которая заполняет A/B/C для всех фактически присутствующих направлений одним запросом, не изменяя их идентификаторы, названия, порядок или состав.
- Существующая общая кнопка генерации остаётся и перед запуском предупреждает, что заполненные значения всех разделов будут перезаписаны.
- Несохранённые ручные или сгенерированные изменения защищаются при уходе из раздела или со страницы диалогом с действиями «Не сохранять», «Сохранить изменения» и закрытием без выполнения перехода.
- **BREAKING** Для новых вакансий пять стандартных ABC-направлений создаются с пустыми описаниями A/B/C; существующие вакансии не мигрируются.
- **BREAKING** Пустые описания A/B/C становятся допустимыми при сохранении и не являются обязательным условием анализа; при отсутствии определения конкретная ABC-оценка должна трактоваться как неоцениваемая, без выдумывания правил моделью.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `vacancy-profile`: поэтапная LLM-генерация и редактируемые промпты, защита несохранённых изменений, генерация ABC по текущему составу направлений и новый контракт необязательных описаний A/B/C.

## Impact

- UI настроек вакансии, модальные окна подтверждения и защита навигации.
- Серверные API и RouterAI-контур генерации профиля вакансии.
- Персистентность вакансий, версий профиля и отдельных промптов генерации.
- Схемы структурированных ответов для одиночной, общей и ABC-генерации.
- Создание новой вакансии и валидация ABC-профиля без миграции существующих записей.
- Приёмочные тесты, LLM boundary-тесты и обязательный регрессионный контур.
