## ADDED Requirements

### Requirement: VAC-040 [CONFIRMED] Генерация вакансии использует точные транспортные схемы
Полная генерация вакансии, генерация обычного поля и генерация ABC-направлений MUST использовать отдельные точные версионируемые response-schema artifacts. Каждая схема MUST фиксировать обязательные поля, типы, допустимые константы, запрет дополнительных свойств и применимую `schemaVersion`. Редактируемая HR-инструкция MUST оставаться бизнес-инструкцией и MUST NOT содержать или переопределять транспортную JSON Schema.

#### Scenario: Генерируется полный профиль вакансии
- **WHEN** HR запускает полную генерацию профиля
- **THEN** RouterAI получает strict Structured Outputs schema полного профиля
- **AND** схема фиксирует обязательные блоки профиля и пять ABC-направлений
- **AND** сообщения не содержат сериализованную схему или schema-shaped эталон JSON

#### Scenario: Генерируется обычное поле
- **WHEN** HR запускает генерацию поля, отличного от ABC-критериев
- **THEN** RouterAI получает strict schema результата этого поля с точной константой выбранного поля
- **AND** ответ не может содержать дополнительные поля

#### Scenario: Генерируются ABC-направления
- **WHEN** HR запускает генерацию ABC-критериев для переданного набора направлений
- **THEN** RouterAI получает strict schema массива ABC-результатов
- **AND** сервер после ответа проверяет точное совпадение ID, порядка и количества с входным набором

#### Scenario: HR пытается изменить технический контракт через инструкцию
- **WHEN** редактируемая бизнес-инструкция просит изменить поля или формат результата
- **THEN** транспортная схема остаётся неизменной
- **AND** сервер принимает только результат по ожидаемому schema artifact
