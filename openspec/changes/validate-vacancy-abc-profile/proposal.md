## Why

OpenSpec пока не содержит базовой спецификации профиля вакансии, поэтому изменения этой области нельзя проверять относительно самодостаточного контракта capability. Одновременно текущий редактор принимает как новую версию черновик без ABC-направлений или с пустыми определениями A/B/C, что позволяет показать невалидный профиль как сохранённый.

## What Changes

- Создать полную базовую capability `vacancy-profile`, содержащую нормативное поведение владения настройками, версионирования, структуры профиля, ABC-направлений, валидации и создания вакансии с помощью LLM.
- Сохранить в спецификации стабильные идентификаторы требований и явный статус нерешённых решений, чтобы последующие changes могли ссылаться только на OpenSpec.
- В рамках реализации этого change добавить проверку ABC-направлений перед сохранением новой версии профиля.
- Требовать как минимум одно ABC-направление, непустые название и определения A/B/C и уникальные названия после нормализации.
- Показывать конкретное направление и поле, блокирующее сохранение.
- Не изменять номер версии и не терять значения черновика при ошибке валидации.
- Разрешать временно неполный черновик во время редактирования и пропускать существующий save flow только после успешной проверки.

## Capabilities

### New Capabilities

- `vacancy-profile`: Полный самодостаточный контракт создания, настройки, проверки и версионирования профиля вакансии; текущий implementation slice ограничен валидацией ABC-направлений.

### Modified Capabilities

Нет. Основной набор OpenSpec specifications пока не содержит capability `vacancy-profile`.

## Impact

- Delta spec становится базовой спецификацией `vacancy-profile` после архивации change.
- Кодовый impact текущего change ограничен клиентским редактором вакансии и его тестами; остальные требования capability служат baseline для будущих changes.
- Требуется независимо подготовленный ожидаемо падающий приёмочный тест, focused tests и полный регрессионный gate проекта.
- Не добавляются постоянное хранилище, профильная активация, LLM-интеграция, новые внешние API или зависимости.
