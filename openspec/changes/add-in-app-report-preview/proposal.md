## Why

Google Shared Drive должен оставаться нормативным хранилищем и архивом результатов, но чтение готовых документов не должно выводить HR из приложения. Текущая карточка кандидата не различает два нормативных PDF, не предоставляет защищённый быстрый просмотр и использует неоднозначное действие скачивания общего «отчёта».

## What Changes

- После успешной обработки показывать в разделе `Материалы` карточки кандидата только две кнопки результатов последней успешной версии: `Итоги` и `ABC-тест`.
- Не показывать HR прежние result versions; при подтверждённом reprocess сразу скрывать предыдущую пару до публикации новой valid pair.
- По каждой кнопке открывать соответствующий сохранённый PDF в read-only modal поверх карточки без перехода в Google Drive или раскрытия прямого публичного URL.
- Проверять доступ к содержимому через приложение; закрывать modal без навигации и возвращать карточку в обычное default state без требования сохранять вкладку, scroll, раскрытые блоки, историю или focus.
- Сохранять краткую сводку с итоговой рекомендацией в карточке кандидата.
- Не показывать ложный успех при недоступном, повреждённом, неопубликованном либо не соответствующем актуальной версии PDF; состояние `READY` разрешать только при валидной согласованной паре файлов.
- Удалить общую кнопку `Скачать отчёт`; скачивание выполнять только из modal отдельно для выбранного документа `Итоги` либо `ABC-тест`.
- Разрешить стандартные read-only PDF viewer actions: scroll, zoom, search, print и save/download открытого документа; при ошибке открытия давать только понятное сообщение и закрытие.
- Расширить обязательный приёмочный контур сценариями наличия пары результатов, защищённого модального просмотра, соответствия версии, read-only поведения, возврата карточки в default state и корректной обработки ошибок.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `reporting-and-notifications`: Добавить контракт отображения последней успешной пары PDF в карточке, защищённого read-only modal preview и отдельного экспорта выбранного документа без общей кнопки скачивания.
- `candidate-workflow`: Изменить visibility прежнего результата при reprocess: old pair скрывается и не используется как fallback.
- `quality-gates`: Добавить наблюдаемые положительные и отрицательные сценарии приёмки in-app preview и однозначного экспорта двух результатов.

## Impact

- Затрагиваются карточка кандидата, раздел `Материалы`, механизм защищённой выдачи сохранённых PDF, modal preview и аудит экспорта.
- Google Shared Drive сохраняет роль нормативного хранилища; имена, версии, контрольные суммы и неизменяемость PDF остаются под требованиями REP-004–REP-009.
- Потребуются независимо подготовленные ожидаемо падающие приёмочные тесты и полный регрессионный набор проекта перед реализацией.
- Конкретные UI-библиотеки, способы встраивания PDF, модели и provider endpoints этим change не фиксируются.
