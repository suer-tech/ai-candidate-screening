# Рабочий реестр продуктовых вопросов

**Статус: WORKING DRAFT / НЕНОРМАТИВНЫЙ ДОКУМЕНТ.**

Этот файл используется только для пошагового обсуждения с владельцем продукта. Он не является согласованной спецификацией, proposal, design, tasks или delta spec. Ответы становятся нормативными только после явного подтверждения владельцем и отдельного переноса в planning artifacts change.

## Уже подтверждённые решения

- Сценарий входит в MVP.
- В разделе `Материалы` карточки кандидата показываются две кнопки результатов последней успешной версии: `Итоги` и `ABC-тест`.
- Кнопки появляются автоматически после успешной обработки и публикации валидной пары результатов.
- Каждый документ открывается в защищённом read-only modal поверх карточки кандидата.
- Для чтения документа HR не переходит в Google Drive и не покидает карточку кандидата.
- Приложение проверяет доступ и не раскрывает прямой публичный URL Google Drive.
- Каждый документ скачивается отдельно и только из modal соответствующего документа.
- Общая или неопределённая кнопка `Скачать отчёт` в карточке удаляется.
- Краткая сводка с рекомендацией остаётся в карточке кандидата.

## Решённые вопросы

1. **RESOLVED.** Прежние версии результатов HR не нужны и не должны отображаться. В карточке доступны только результаты актуальной успешной обработки; пользовательский интерфейс не предоставляет просмотр или скачивание прежних версий.

2. **RESOLVED.** При запуске повторной обработки предыдущие результаты сразу скрываются до появления новой опубликованной пары документов. Старая пара не сохраняется рядом с выполняющимся запуском и не показывается как fallback, в том числе пока новая пара ещё не опубликована.

3. **SUPERSEDED В ЧАСТИ РУЧНОГО ПОВТОРА.** При ошибке обработки HR видит понятный статус; автоматические попытки выполняются согласно specs. Позднее владелец подтвердил отдельную кнопку ручной повторной обработки для terminal `FAILED` после исчерпания автоматических повторов. Внутри modal ошибки открытия PDF по-прежнему нет recovery-action кроме закрытия.

4. **RESOLVED.** Во время первой обработки, пока готовых результатов нет, раздел `Материалы` не показывает результатные элементы, заглушки или disabled-кнопки. Кнопки `Итоги` и `ABC-тест` появляются только после успешной обработки кандидата и публикации валидной пары документов.

5. **RESOLVED.** После закрытия modal карточка кандидата возвращается к обычному состоянию по умолчанию. Сохранять активную вкладку, позицию прокрутки, раскрытые блоки, выбранную историю или фокус элемента не требуется.

6. **RESOLVED.** В modal разрешены стандартные действия PDF-viewer: чтение и прокрутка, увеличение и уменьшение масштаба, поиск, печать и сохранение либо скачивание именно открытого документа. Это совместимо с правилом, что скачивание доступно только внутри modal конкретного документа.

7. **RESOLVED.** При временной ошибке открытия PDF modal показывает понятное сообщение об ошибке и предлагает только закрыть окно. Ручные recovery-действия, повторная загрузка или запуск повторного анализа со стороны HR не требуются.

8. **RESOLVED.** Отдельное audit-событие для каждого preview PDF не требуется. Обычная история анализа сохраняется, а существующие правила аудита экспорта и скачивания остаются без изменений.
