# ACC-VAC-ABC-001 — валидация ABC-профиля на границе сохранения

## Трассировка и независимость

- Связанные требования: `VAC-017`, `VAC-019`.
- Автор тест-кейса: независимый Codex-субагент `/root/vacancy_abc_acceptance`.
- Исполнитель RED-прогона: тот же независимый субагент.
- Заявление: автор и исполнитель не участвовали в основной реализации проверяемого поведения и не изменяли production/app-код.
- Тестовые данные: полностью синтетические; секреты и персональные данные реальных кандидатов отсутствуют.

## Цель

Подтвердить, что граница `Сохранить новую версию` отклоняет неполный или неоднозначный ABC-профиль, сохраняет черновик без скрытой нормализации и изменяет версию ровно один раз только для валидного профиля.

## Предусловия и конфигурация

- Рабочий каталог: `web/`.
- Node.js `v24.14.0`, npm `11.9.0`.
- Пакет приложения: `site-creator-vinext-starter@0.1.0`.
- Проверяемый исходник при RED: `app/page.tsx`, SHA-256 `9B62FED88B2D7A4D63F69B31DE056851FDD1E04D1FB7AD3CE536539FFBE45045`.
- Реальный `VacancySettings` загружается во временный каталог через TypeScript transpilation. Test double заменяет только React hooks и JSX runtime; обработчики, условия и state transitions берутся из production-компонента.

## Синтетические данные

Исходная версия вакансии — `7`. Черновик содержит два направления в заданном порядке:

1. `standard-productivity`, origin `standard`, название `Продуктивность`, непустые A/B/C.
2. `custom-collaboration`, origin `custom`, название `Командная работа`, непустые A/B/C.

Для отрицательных проверок создаются независимые копии черновика. Изменяется только проверяемое поле.

## Шаги и ожидаемый результат

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Отрендерить редактор и открыть `ABC-критерии` | Видны версия 7, два направления и исполняемое действие сохранения |
| 2 | Сохранить список без направлений | Отказ с причиной; версия остаётся 7; пустой черновик остаётся доступным |
| 3 | Поочерёдно сохранить название `""` и whitespace | Каждая попытка отклонена; версия и черновик не меняются |
| 4 | Для каждого `gradeA`, `gradeB`, `gradeC` поочерёдно сохранить `""` и whitespace | Каждая попытка отклонена с указанием оценки; версия и черновик не меняются |
| 5 | Сохранить названия `Инициатива` и `  иНиЦиАтИвА  ` | Попытка отклонена как дубликат после trim и регистронезависимого сравнения |
| 6 | После каждого отказа перечитать карточки | Значения, ids, origin и порядок полностью совпадают с черновиком до попытки |
| 7 | Один раз сохранить исходный валидный профиль | Версия становится ровно 8; черновик не меняется; ровно одно подтверждение содержит версию 8 |
