## Приёмочный контур

- После согласования спецификации исполняемые приёмочные тесты пишет независимый субагент, не участвовавший в основной реализации.
- Перед production-релизом и после изменений кода, моделей, инструкций, схем или интеграций обязателен полный набор `E2E-VAC-001`, `E2E-TRN-001`, `E2E-ABC-001`, `E2E-RESULT-001`.
- Реализация нового поведения начинается с ожидаемо падающего приёмочного теста и считается завершённой только после прохождения этого теста и полного регрессионного набора.

Main specifications из `openspec/specs/` являются единственным источником согласованных продуктовых требований. Active changes из `openspec/changes/` описывают предлагаемые отклонения и не заменяют main specs до синхронизации. Неопределённые решения помечены `TBD`; их нельзя заменять неявными предположениями при реализации.
